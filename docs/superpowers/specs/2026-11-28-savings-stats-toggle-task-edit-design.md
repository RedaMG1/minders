# Savings, a stats toggle, and editing tasks

Date: 2026-11-28. Size: a small change. Approved in conversation ("yes do it and publish").

## 1. Savings kept apart from spending

**Why:** money put aside as savings was counted as spent, which made the month look worse than it was.

**Decided**
- **Marking:** a **"This is savings"** switch on a top-level category's edit sheet. Its subcategories count as savings too.
- **Spending excludes savings:** money in savings never counts toward "Spent in <month>", the monthly plan (savings limits are left out), or the Stats section (total, pace, bars, chart, biggest items, over-limit).
- **Budget page:**
  - A **Savings** card shows "Saved in <month>", followed by a **Savings** section listing the savings categories.
  - Spending categories stay in the main list.
- **A savings category's own page** says "saved" where others say "spent".

## 2. Hide or show the stats

- **Button:** the Stats section has a **Hide stats** / **Show stats** button.
- **Hidden view:** when hidden, only the section's title and the button show.
- **Remembered on this device:** like the theme, the choice isn't synced.

## 3. Edit a task on Today or Tomorrow

- **Editing:** tapping a task's name opens an **Edit task** sheet with its name; Save keeps the change.
- **Empty names:** a name can't be saved empty.
- **Ticking:** ticking done is on the circle only.
- **Module tasks:** they keep their module's name, so tapping the name opens the module's contents instead, the same as the list button.

**Left to the builder:** exact looks, in the app's current style.
